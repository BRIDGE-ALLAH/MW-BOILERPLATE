# M03 — Advanced Quality and Operations

**Priority:** P3  
**Objective:** Prove browser behavior, security posture, CI gates, and static container deployment.

## Tasks

- M03-001 browser E2E and accessibility checks.
- M03-002 CI, dependency, and Docker build validation.
- M03-003 Docker/Coolify runtime verification.
- M03-004 final security and architecture reconciliation.

## Exit criteria

CI runs formatting, lint, unit/integration, WASM, production build, dependency audit, and Docker build. Browser suite covers routes, navigation, theme, forms, dialog keyboard flow, responsive layout, and console errors. Docker image builds and serves the static app with a working health check. Evidence links/logs are recorded.
