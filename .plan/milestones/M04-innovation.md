# M04 — Innovation and Future Targets

**Priority:** P4  
**Objective:** Evaluate future capabilities only when a real consumer, product requirement, or platform opportunity justifies them.

## Task

- M04-001 evaluate consumer-backed future targets.

## Candidate areas

Desktop/mobile packaging, SSR/hydration, shared icon/token/theme crates, shared testing utilities, and advanced agent tooling. These are opportunities, not commitments. Each requires a documented use case, compatibility review, ownership boundary, maintenance cost, and migration path.

## Exit criteria

A decision record recommends adopt/defer/reject with evidence and does not create unused crates or experimental production dependencies.
