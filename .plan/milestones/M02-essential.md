# M02 — Essential UX and Moon UI

**Priority:** P2  
**Objective:** Grow a coherent, neutral, accessible component foundation and integrate it into the sample app.

## Tasks

- M02-001 component API, design token, and accessibility contract.
- M02-002 primitives.
- M02-003 accessible form components.
- M02-004 feedback and application states.
- M02-005 dialog.
- M02-006 showcase integration.

## Exit criteria

Every shipped component has a public API, defaults, variants/sizes where relevant, disabled/loading behavior, accessible naming, keyboard behavior, CSS ownership, usage example, and tests. Dialog is not accepted without focus entry/return, Escape handling, and keyboard coverage.
